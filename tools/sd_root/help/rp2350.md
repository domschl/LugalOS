# RP2350 Hardware Reference Guide

[Documentation](index.md) > [Administrator Manual](admin.md) > [Board Reference Guides](boards.md) > **RP2350 Guide**

---

This document provides hardware specifications, port topologies, and flashing details for **Raspberry Pi Pico 2** and **Waveshare RP2350-LCD-7** boards (`rp2350-terminal`, `rp2350-chess`, `rp2350-clock`, `rp2350-wifi`, `rp2350-gateway`).

---

## 1. Dual CDC-ACM USB Serial Architecture

RP2350 devices running LugalOS expose **two distinct USB CDC-ACM serial interfaces**:
* **Interface 0 (`if00`):** Interactive `lsh` shell & Lisp REPL console operating at **115,200 baud**.
  * Symlink: `/dev/serial/by-id/usb-LugalOS_*_Dual_CDC_ACM_*-if00`
* **Interface 2 (`if02`):** Dedicated binary 9P filesystem and network tunnel (`link_usb_cdc`).
  * Symlink: `/dev/serial/by-id/usb-LugalOS_*_Dual_CDC_ACM_*-if02`

---

## 2. Automated BOOTSEL Entry (1200-Baud Touch)

The LugalOS USB CDC stack implements the 1200-baud touch protocol on the console interface (`if00`). Opening and immediately closing the port at 1200 baud triggers a deferred reboot directly into the RP2350 bootrom BOOTSEL mode:

```python
import serial
with serial.Serial("/dev/serial/by-id/usb-LugalOS_rp2350_Dual_CDC_ACM_...-if00", 1200):
    pass
```

### Manual Fallback
If the running firmware is unresponsive or in a hard fault state:
1. Hold down the physical **BOOTSEL** button while connecting the USB cable (or pressing RUN reset).
2. The board enumerates as a USB mass storage volume named `RPI-RP2`.

## 3. Build & Flashing Workflows

### Building Firmware
```bash
# 7" LCD Workstation Terminal
ninja -C build/rp2350-terminal

# Dedicated Chess Computer
ninja -C build/rp2350-chess

# Wi-Fi Enabled Pico 2 W
ninja -C build/rp2350-wifi
```

> [!CAUTION]
> Always flash `build/rp2350-terminal/lugalos.uf2` for the 7" LCD terminal. Flashing the generic `rp2350` build will leave the LCD uninitialized (blank/black).

### Flashing with `picotool`
Once the board is in BOOTSEL mode:
```bash
# Flash kernel image
/home/dsc/gith/pico/pico-sdk-tools/picotool/picotool load -f build/rp2350-terminal/lugalos.uf2 -x

# Optional: flash embedded flashfs filesystem image
/home/dsc/gith/pico/pico-sdk-tools/picotool/picotool load -f build/rp2350-terminal/flashfs.uf2
```

## 4. MicroSD Storage Synchronization via 9P (`tools/p9sync.py`)

To synchronize files on the board's MicroSD card without unmounting the physical card or interrupting running tasks:

```bash
uv run --project host/p9lib python3 tools/p9sync.py \
    --serial /dev/serial/by-id/usb-LugalOS_*_Dual_CDC_ACM_*-if02 \
    --src build/rp2350-terminal/sd_root \
    --dst /sd0
```

`tools/p9sync.py` is idempotent and strictly preserves user directories (`/sd0/CHESS/`, history logs, etc.).

## 5. Wireless Link via Co-Processor (ESP32-C6)

On the **RP2350-LCD-7**, header **H7** exposes UART0 for high-speed Wi-Fi co-processing:
* **Connection:** Header H7 connects to an external ESP32-C6-Zero running LLP at **921,600 baud** with crossed TX/RX lines.
* **Autonomous Boot:** An autonomous C6 booting without USB arms LLP on its UART0 automatically.
* **Power Supply:** The C6 must receive 5V power from a separate USB charger. H7's 3.3V rail cannot sustain Wi-Fi transmit bursts.

## 6. SRAM on the Boards Without a Panel

The heap is whatever the kernel image leaves of the RP2350's 520 KB, and a Pico 2 W's
boot, Wi-Fi and a compile (the compiler takes a 112 KB arena at once) use most of it.
Three build settings keep it as large as the board allows (`/proc/meminfo`, *Pages Total*):

| Setting | Where | What it gives back |
| :--- | :--- | :--- |
| One reader window | `READER_MAX_INSTANCES` in `drivers/include/drivers/reader_view.h`: 1 on an RP2350 without `CONFIG_LCD_PCLK_GPIO` (and on the C6), 4 elsewhere | 22 KB |
| No core-1 stack | `__stack1_size` in `CMakeLists.txt`: 16 KB only where the SMP scheduler or the PIO-USB engine (`CONFIG_PIOUSB_DP_GPIO`, the terminal) runs on core 1, none elsewhere | 16 KB |
| A sensor skip-list | `CONFIG_SENSOR_SKIP` in the board file, comma-separated driver names the hub never registers. The Pico 2 W skips `mics6814`: with nothing wired, its probe of 0x04 was answered at boot by nothing, and the hub then ran a 12 KB sampler task for the rest of the uptime | 12 KB of task stack on the boots it triggered |

With them a Pico 2 W has 80 heap pages (the build before the update layer had 71).
Lisp's pools are the next candidates, and are board settings already
(`CONFIG_LISP_NODE_POOL`, `CONFIG_LISP_STRING_POOL`; the C6 runs 512 nodes and 192
strings, the RP2350 default is 1024 nodes and about 26 KB of strings), but they decide
how much Lisp a board can run, and are left alone until a board needs it.

## 7. Pinouts & Hardware Wiring

All RP2350 board pin assignments are defined in `cmake/board-rp2350*.cmake` (the single source of truth for `lugalos_config.h`).

### `rp2350-chess` (Pico 2 Chess Appliance)

Defined in `cmake/board-rp2350.cmake`:

| Subsystem | Bus / Type | GPIO Pins | Notes |
| :--- | :--- | :--- | :--- |
| **UART0** | Console / 9P | `GP0` (TX), `GP1` (RX) | 115,200 baud |
| **I2C0** | RTC / Sensors / CLCD | `GP4` (SDA), `GP5` (SCL) | DS1307/DS3231 RTC, I2C sensors, optional 20x4 HD44780 (`0x27`/`0x3F`) |
| **TM1638** | 3-wire (bit-banged) | `GP6` (STB), `GP7` (CLK), `GP8` (DIO) | 8-digit 7-seg + 8 LEDs + 8 keys |
| **SPI1** | MicroSD Card | `GP10` (SCK), `GP11` (MOSI), `GP12` (MISO), `GP13` (CS) | `/sd0/CHESS/` |
| **SPI0** | ST7735 TFT (160x128) | `GP18` (SCK), `GP19` (MOSI), `GP17` (CS), `GP20` (DC), `GP21` (RST) | Connect VCC to `3V3` |
| **Status LEDs** | GPIO | `GP25` (onboard), `GP16` (external) | Heartbeat / status |

### `rp2350-sensor` (Pico 2 W Environmental Sensor Node)

Defined in `cmake/board-rp2350-sensor.cmake`:

| Subsystem | Bus / Type | GPIO Pins | Notes |
| :--- | :--- | :--- | :--- |
| **UART0** | Console | `GP0` (TX), `GP1` (RX) | 115,200 baud |
| **Status LED** | GPIO | `GP2` | External heartbeat LED |
| **I2C0** | BME280 / I2C Sensors | `GP4` (SDA, pin 6), `GP5` (SCL, pin 7) | Power from `3V3` (pin 36) and `GND` (pin 38); internal pull-ups enabled |
| **UART1** | MH-Z19B CO2 Sensor | `GP8` (TX), `GP9` (RX) | 9600 baud (cross TX/RX to sensor) |
| **CYW43439** | Internal gSPI | `GP23` (ON), `GP24` (DATA), `GP25` (CS), `GP29` (CLK) | Internal to Pico 2 W module (not on header) |

### `rp2350-gateway` (Pico 2 Wired Ethernet Gateway)

Defined in `cmake/board-rp2350-gateway.cmake`:

| Subsystem | Bus / Type | GPIO Pins | Notes |
| :--- | :--- | :--- | :--- |
| **UART0** | Console | `GP0` (TX), `GP1` (RX) | 115,200 baud |
| **I2C0** | RTC / Sensors | `GP4` (SDA), `GP5` (SCL) | Shared I2C bus |
| **UART1** | SLIP 9P Downlink | `GP8` (TX), `GP9` (RX) | Downlink to chess or clock board |
| **SPI1** | MicroSD Card | `GP10` (SCK), `GP11` (MOSI), `GP12` (MISO), `GP13` (CS) | `/sd0` |
| **SPI0** | ENC28J60 Ethernet | `GP18` (SCK), `GP19` (MOSI/SI), `GP16` (MISO/SO), `GP17` (CS), `GP20` (RST), `GP21` (INT) | 3.3V only |
| **Status LED** | GPIO | `GP25` (onboard) | Heartbeat |

| Subsystem | Bus / Type | GPIO Pins | Notes |

### `rp2350-wifi` (Pico 2 W Wireless Node)

Defined in `cmake/board-rp2350-wifi.cmake`: `UART0` (`GP0`/`GP1`), `I2C0` (`GP4`/`GP5`), `SPI1` MicroSD (`GP10`-`GP13`), external LED (`GP9`), and internal CYW43439 (`GP23`/`GP24`/`GP25`/`GP29`).

### `rp2350-terminal` (Waveshare RP2350-LCD-7)

Defined in `cmake/board-rp2350-terminal.cmake`: `UART0` / ESP32-C6 LLP on header H7 (`GP16` TX / `GP17` RX, 921,600 baud), `I2C1` touch/RTC (`GP6` SDA / `GP7` SCL), `SPI1` MicroSD (`GP10` SCK / `GP11` MOSI / `GP12` MISO / `GP15` CS), `PIO-USB` host (`GP42` D+ / `GP43` D-), PSRAM `/CS` (`GP0`), and 800x480 RGB LCD (`GP20`, `GP23`, `GP24`+, `GP41`, `GP44`, `GP45`).
