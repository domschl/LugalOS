# RP2350 Hardware Reference Guide

[Documentation](index.md) > [Administrator Manual](admin.md) > [Board Reference Guides](boards.md) > **RP2350 Guide**

---

This document provides hardware specifications, port topologies, and flashing details for **Raspberry Pi Pico 2** and **Waveshare RP2350-LCD-7** boards (`rp2350-terminal`, `rp2350-chess`, `rp2350-clock`, `rp2350-wifi`, `rp2350-gateway`).

---

## 1. Dual CDC-ACM USB Serial Architecture

RP2350 devices running LugalOS expose **two distinct USB CDC-ACM serial interfaces**:
* **Interface 0 (`if00`):** Interactive `lsh` shell & Lisp REPL console operating at **115,200 baud**.
  * Symlink: `/dev/serial/by-id/usb-LugalOS_*_Dual_CDC_ACM_*-if00`
* **Interface 2 (`if02`):** Dedicated binary 9P filesystem and network tunnel (`link_usb_cdc`).
  * Symlink: `/dev/serial/by-id/usb-LugalOS_*_Dual_CDC_ACM_*-if02`

---

## 2. Automated BOOTSEL Entry (1200-Baud Touch)

The LugalOS USB CDC stack implements the 1200-baud touch protocol on the console interface (`if00`). Opening and immediately closing the port at 1200 baud triggers a deferred reboot directly into the RP2350 bootrom BOOTSEL mode:

```python
import serial
with serial.Serial("/dev/serial/by-id/usb-LugalOS_rp2350_Dual_CDC_ACM_...-if00", 1200):
    pass
```

### Manual Fallback
If the running firmware is unresponsive or in a hard fault state:
1. Hold down the physical **BOOTSEL** button while connecting the USB cable (or pressing RUN reset).
2. The board enumerates as a USB mass storage volume named `RPI-RP2`.

## 3. Build & Flashing Workflows

### Building Firmware
```bash
# 7" LCD Workstation Terminal
ninja -C build/rp2350-terminal

# Dedicated Chess Computer
ninja -C build/rp2350-chess

# Wi-Fi Enabled Pico 2 W
ninja -C build/rp2350-wifi
```

> [!CAUTION]
> Always flash `build/rp2350-terminal/lugalos.uf2` for the 7" LCD terminal. Flashing the generic `rp2350` build will leave the LCD uninitialized (blank/black).

### Flashing with `picotool`
Once the board is in BOOTSEL mode:
```bash
# Flash kernel image
/home/dsc/gith/pico/pico-sdk-tools/picotool/picotool load -f build/rp2350-terminal/lugalos.uf2 -x

# Optional: flash embedded flashfs filesystem image
/home/dsc/gith/pico/pico-sdk-tools/picotool/picotool load -f build/rp2350-terminal/flashfs.uf2
```

## 4. MicroSD Storage Synchronization via 9P (`tools/p9sync.py`)

To synchronize files on the board's MicroSD card without unmounting the physical card or interrupting running tasks:

```bash
uv run --project host/p9lib python3 tools/p9sync.py \
    --serial /dev/serial/by-id/usb-LugalOS_*_Dual_CDC_ACM_*-if02 \
    --src build/rp2350-terminal/sd_root \
    --dst /sd0
```

`tools/p9sync.py` is idempotent and strictly preserves user directories (`/sd0/CHESS/`, history logs, etc.).

---

## 5. Wireless Link via Co-Processor (ESP32-C6)

On the **RP2350-LCD-7**, header **H7** exposes UART0 for high-speed Wi-Fi co-processing:
* **Connection:** Header H7 connects to an external ESP32-C6-Zero running LLP at **921,600 baud** with crossed TX/RX lines.
* **Autonomous Boot:** An autonomous C6 booting without USB arms LLP on its UART0 automatically.
* **Power Supply:** The C6 must receive 5V power from a separate USB charger. H7's 3.3V rail cannot sustain Wi-Fi transmit bursts.
